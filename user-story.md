
# User Stories — Accounts Microservice

## REST API

### Read an account from the service
As a service user, I want to retrieve an account by ID so that I can view its details.

### List all accounts in the service
As a service user, I want to list accounts so that I can view available records.

### Update an account in the service
As a service user, I want to update an account so that its details remain current.

### Delete an account from the service
As a service user, I want to delete an account so that obsolete records can be removed.

### Create an account
As a service user, I want to create an account so that new customers can be registered.

## Continuous Integration

As a developer, I want automated linting and unit tests on code changes so that defects are identified early.

## Security

As a service owner, I want security headers and CORS policies so that the API has appropriate browser-facing protections.

## Containerization

As a developer, I want to package the microservice into a Docker image so that it can run consistently.

## Kubernetes Deployment

As an operator, I want to deploy the container to Kubernetes so that the service can run in a managed environment.

## Continuous Delivery

As an operator, I want an automated CD pipeline so that validated application changes can be deployed consistently.
